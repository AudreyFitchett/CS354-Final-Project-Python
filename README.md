## Testing

This project uses pytest to ensure data transformation and model inference remain consistent.

Windows (PowerShell / CMD)
Initial Setup:
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
The Build Pipeline: 
4. python data_setup.py 
5. python train_model.py 
6. python -m pytest test_model.py -v

Linux and macOS
Initial Setup:
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
The Build Pipeline:
4. python3 data_setup.py
5. python3 train_model.py 
6. python3 -m pytest test_model.py -v
